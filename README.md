# gloomy-cpp

A GPU-accelerated, keyboard-centric UI library in C++23 on raw Vulkan: the C++ respin of [gloomy](https://github.com/KlingelDev/gloomy) (Rust, wgpu).

Built for data-heavy applications such as the X-conomy game client: large virtualised tables with sorting, filtering, column operations and search; long rich text (contracts, logs) that is searchable; themes; SDF-rendered primitives; a flexbox and grid layout engine.

Status: just started. See `CLAUDE.md` for conventions and `docs/` for the design.
